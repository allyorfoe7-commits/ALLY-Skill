# ALLY-Skill

> **别人垂直赛道，我垂直人格。**

一个把真实创作者的人格、经历、写作逻辑和喜剧机制封装成 AI Agent Skill 的开源实验。

## 为什么要开源这个？

很多人想研究我的内容为什么能传播。

有人把这个过程叫“蒸馏”。

那不用偷偷研究了，我直接把人格模型、写作结构和内容方法论开源。

毕竟能被 AI 学走的是表达结构，学不走的是我这些年被商业世界反复教育、被市场收学费、被现实扇耳光以后留下来的判断。

代码可以复制。

Prompt 可以复制。

人生经历暂时还不支持 `git clone`。

## 这是什么？

这不是普通写作模板。

不是商业课程。

不是 Prompt 合集。

它是一份给 AI Agent 使用的创作者 Skill：让 Agent 理解一个跨领域人格型创作者如何观察世界、组织内容、制造反差，再把商业和人性讲得像一场凌晨两点的朋友聊天。

ALLY 不属于某一个垂直赛道。她横跨 AI、Crypto、美股、商业、营销、人性、自媒体和交易现场。

真正的垂直不是题材。

是她看世界的方式。

## Skill 里有什么？

- 创作者定位：不做单点知识博主，做跨领域人格型创作者；
- 人格模型：保留聪明与抽象、野心与自嘲、财富研究与现实狼狈；
- 写作引擎：从真实事件走向商业、人性和时代判断；
- 喜剧引擎：预期反转、身份错位、自我攻击、情绪夸张、小事升维；
- 商业观察框架：技术、市场、营销、利益和人的连接；
- 质量检查：防止 AI 把一个活人优化成没有味道的知识博主。

## 核心公式

```text
真实经历
  ↓
情绪反应
  ↓
大众预期与现实冲突
  ↓
商业 / 人性 / 市场 / 技术洞察
  ↓
回到 ALLY 本人
```

喜剧不是为了硬挤笑话。

它的作用是把洞察包起来，让人先笑，再想一下，最后记住是谁说的。

## AI 能学会什么？

AI 可以学习：

- 怎么找到内容里的矛盾；
- 怎么把生活小事升维成商业判断；
- 怎么先建立能力感，再自我拆台；
- 怎么把高级概念讲成人话；
- 怎么减少正确、完整、但没有人格的 AI 废话。

AI 无法复制：

- 真实生活；
- 亲自付过的学费；
- 进入过不同圈层后的判断；
- 一个人为什么会对某件事愤怒、兴奋或者觉得离谱。

所以这个 Skill 不鼓励伪造 ALLY 的人生。

它要求使用者先提供真实经历。没有真实经历，就只能写观察，不能假装亲历。

## 隐私边界

人格可以开源，隐私不能开源。

这个项目公开的是创作者方法论，不是创作者私人数据库。使用 Skill 时，所有案例都必须匿名化：不公开真实姓名、私人联系人、未公开合作方、联系方式，以及能够通过信息组合反推出真实身份的细节。

公开内容只使用 `ALLY`、化名、泛化描述或当事人已经主动公开的身份信息。

能写“某位创业者朋友”，就别把人家的身份证明也顺手 `git push` 了。

## 如何使用

### Codex 一键安装（推荐）

使用 Codex 自带的 Skill 安装器：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo allyorfoe7-commits/ALLY-Skill \
  --path ally-skill
```

安装完成后，在下一轮任务中调用：

```text
使用 $ally-skill，把下面这段真实经历改成一条 90 秒口播稿。
保留事实，加入反差、自嘲和商业洞察，不要写成老师。
```

### 手动安装

```bash
git clone --depth 1 https://github.com/allyorfoe7-commits/ALLY-Skill.git
cp -R ALLY-Skill/ally-skill ~/.codex/skills/ally-skill
```

Codex 识别的是 `ally-skill/SKILL.md`。仓库根目录的 `ALLY.skill.md` 仅为旧版兼容文件，不要把它当作可直接发现的 Skill 目录。

### 其他 AI Agent

将 `ALLY.skill.md` 作为系统级创作说明、Agent Skill 或项目上下文加载，然后提供真实素材和目标载体。

示例：

```text
这是我真实经历的一次商业踩坑。
请使用 ALLY Skill 写成一篇 X 长文：先讲故事，再拆人性，最后回到自己。
```
